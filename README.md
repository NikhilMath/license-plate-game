# license-plate-game

**Plate Chase** — an iPhone game for spotting license plates from all 50 states and DC.

- Tap a plate when you spot it; tap again to remove it.
- Add players, switch who's playing from the top-right menu, and see who's ahead on the Leaderboard.
- Colored dots on each plate show which players have spotted it.
- "New Road Trip" (Leaderboard ⋯ menu) clears everyone's plates.

## Run it

Open `LicensePlateGame/LicensePlateGame.xcodeproj` in Xcode, pick your iPhone as the run destination, and press ⌘R.
